## Projeto em destaque · Featured project

### [Unimed Tools ↗](https://github.com/HeitorLeite/Unimed-Tools)

**Uma ferramenta que nasceu das tarefas que eu fazia no estágio.**

Na Unimed Lorena, algumas atividades de TI exigiam bastante trabalho manual. Durante a busca por uma maneira de automatizá-las, descobri uma API de acesso ao banco de dados que já existia, mas não era utilizada nesses processos.

A partir disso, idealizei e desenvolvi o **Unimed Tools**, com auxílio de IA no desenvolvimento, para reunir ferramentas de geração de arquivos, relatórios, consultas e correção de XML.

O projeto envolve integração com APIs REST, SQL/Oracle, processamento de dados e desenvolvimento web.

#### Resultados observados

| Processo | Antes | Com a ferramenta | Redução de tempo |
| :--- | ---: | ---: | ---: |
| Geração de grandes massas de arquivos | ~60 min | ~10 min | ~83% |
| Solicitação, desenvolvimento, validação e geração de um novo relatório | ~240 min | ~20 min | ~92% |
| Correção de arquivos XML | ~60 min | ~2 min | ~97% |

> Considerando uma execução de cada atividade: de aproximadamente **6 horas para 32 minutos**, uma redução de **91% no tempo total**.

<sub>Tempos aproximados observados nos processos descritos; os resultados variam conforme o volume e a tarefa.</sub>

<summary><b>Project overview in English</b></summary>

<br />

**A tool that grew out of the tasks I handled during my internship.**

At Unimed Lorena, several IT activities involved time-consuming manual work. While looking for ways to automate them, I discovered an existing database access API that wasn't being used for these workflows.

I designed and developed **Unimed Tools**, using AI assistance during development, to bring together file generation, reporting, data queries, and XML correction tools.

The project involves REST API integration, SQL/Oracle, data processing, and web development.

| Workflow | Before | With the tool | Time reduction |
| :--- | ---: | ---: | ---: |
| Bulk file generation | ~60 min | ~10 min | ~83% |
| Requesting, developing, validating, and generating a new report | ~240 min | ~20 min | ~92% |
| XML file correction | ~60 min | ~2 min | ~97% |

For one execution of each workflow, the combined time went from approximately **6 hours to 32 minutes**, a **91% reduction**.

These are approximate times observed in the described workflows. Results depend on task complexity and data volume.
